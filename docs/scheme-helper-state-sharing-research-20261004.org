* Ownership and invariant
The private helper initializer lazily constructs an identity-keyed cache on
the first helper invocation. It retains at most 128 typed immutable default
state prototypes per parse. Booleans, unsigned integers and empty frame stacks
are the existing admitted defaults. Persistent parameter/state updates share
unchanged entries without mutating prototypes. The exported
=fold-initial-states= remains unchanged and returns fresh nonempty state lists.
Root initialization is not cached. Parameter arity, argument types, bounds,
helper lookup and recursion checks retain their live execution positions.

Outside a request there is no retained prototype. Each =run-event-fold= binds
a fresh pending marker, including exceptional exits. Mutable declarations
are revalidated on subsequent requests; this does not authorize mutation of
admitted IR during a parse. No global cache, public DSL, compatibility path,
Gambit patch, feature removal, or profile/concurrency reduction is added.
