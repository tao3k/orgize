* Task ownership

The former 1,340-line Justfile is now a 27-line entry point. Six imported
owners share its platform settings: Scheme, Runtime, Benchmark, Python,
checks and development. There are 138 recipes, of which 28 are public;
93 obsolete/duplicate recipes were removed and two shared checks added.
This is deletion plus organization, not only hiding the old interface.

Removed tasks include old Fold experiments, parser stash/rebase operations,
stale migration admission counts, repeated field-specific test wrappers and
file-by-file formatting lists. Native index handoff replaces the Rowan task
name. Historical receipts remain historical documentation, not executable
admission for the new candidate.

Retained Scheme suites whose filenames still contain Rowan exercise native
grammar and source semantics. Removing them merely by name would remove
coverage. Direct borrowed-native-view ownership is still a separate gate.

Daily discovery: =just --list=. Private implementation inspection:
=just --dump=. The task-layout check rejects dangling dependencies and
delegated calls. CI's existing Scheme, Contract and Python commands remain.
Rust and Scheme runtime features, real-output watchdogs and the 1,000/10,000
document concurrent benchmark lanes remain. Platform flags stay conditional.
