remain explicit host responsibilities. Their retention is not a raw Org
parser fallback. Existing double-call behavior is retained; replacing a
local operation with FFI is not presented as a performance improvement.

=file:= prefix rewrite; the existing Scheme suffix predicate owns that
decision. Twelve unused outer link/LOGBOOK/table-cookie wrappers are removed
after call-site inspection. Inner native ABI functions and test entrances
are retained. Production library warnings decrease from 42 to 30; strict
lint closure is not claimed and warnings are not suppressed.
