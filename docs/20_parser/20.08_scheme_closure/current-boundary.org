* Fixed architectural boundary

Scheme owns source grammar and semantic algorithms; Rust retains counted
transport, typed row admission, UTF-8 bounds/annotations, graph execution
and explicit environment/process/filesystem effects. Rowan dependencies are
removed, but public parsing still materializes a navigation index from native
events: this is not direct native-view/result lease completion.

Generic Fold execution, byte scanning, state/helper scope, event accumulation
and AOT lowering belong to gerbil-parser. Org retains declarative grammar,
markers, containment and semantic composition. Existing POO-native source
fragment policies already provide delimiter splitting, first splitting and
reference scans; TBLFM consumes them through the public engine facade. The
generic literal-pattern/offset builders now belong to the public engine
interface; Org grammar modules import them directly. Old Org helper definitions
and forwarding wrappers are removed. UTF-8 lengths and ASCII-only case folding
have explicit native acceptance/rejection controls. See
[[file:36-public-source-pattern-and-pr-alignment.org][public engine source-pattern convergence and PR integration]].

AOT removes interpreted compilation work, not synchronous FFI queueing.
Both runtime choices currently execute on one Scheme owner per domain;
Tokio callers do not create independent Scheme domains. Caller admission,
owner service, root/result copy and caller wakeup must be measured separately.
Neither batching nor an actor alone proves bounded long-job or wakeup latency.
