* Public parser and remaining roles

=src/org.rs= aliases Org to OrgAotDocument. Org::parse/try_parse and
ParseConfig::parse call the native Gerbil parser. No Rust syntax parser,
implicit fallback or legacy feature is reachable from these public entries.
Expression syntax and cooked Query/Contract values are native Scheme-owned;
Rust's core_parser.rs admits those values rather than reading raw expressions.
Lint's modular syntax owner emits ORG046 from the owning native compilers.
Host effect validation remains separate from source syntax admission.

This does NOT establish universal downstream Scheme ownership:

- Publishing still interprets BIND/OPTIONS tokens and backend keyword roles
  in =src/semantic_ast/publishing.rs=. This is genuine raw Org source policy,
  unlike Rust numeric admission of a canonical ABI field.
- Capture CLI flag/property parsing is a host command boundary. Capture and
  sparse-tree whitespace normalization need role review; matching a scanner
  method alone does not prove an Org grammar fallback.
- Native scalar Contract policy calls can recur per block/property while
  gathering the registry and linting. Call count/batching is a candidate hot
  path, not a demonstrated root cause of the retained 25ms failure.
- Rust retains graph indexes, typed admission, UTF-8/span validation,
  arithmetic and host effects. Removing those would remove safety boundaries.
