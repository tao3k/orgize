* Cohesive source ownership

An audit beyond Org::parse found raw grammar still in downstream Rust consumers.

- Datetree year/month/day title prefixes and bounded unsigned values.
- Timestamp sorting date/time scans, including Unicode-safe source traversal.
- COLUMNS property/width/title/summary declarations, preserving empty title presence.
- Column summary operator names, precision and checkbox completion syntax.
- Clock scope classification, including treeN and inert external expressions.
- PROPERTY_SCHEMA Org links, macros, file references and contract ids.
- Agenda match clauses, polarity, property comparisons, quoted and brace values;

roots. Property schema shares the existing =contract-reference-funs.ss= owner.

followed by typed graph traversal, lookup, ordering and arithmetic. Agenda's
seven host lexer/parser helpers are removed; public types and query execution
remain. No reader/evaluator, JSON grammar transport or kernel patch is added.

The benchmark adapter fingerprint includes all seven downstream Rust owners,
so previous fingerprints cannot silently qualify a changed host adapter.
