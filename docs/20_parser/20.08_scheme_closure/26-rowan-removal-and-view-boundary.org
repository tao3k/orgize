* The second materialization is not closed

Public parsing still follows native Scheme events ->
=parse_generated_events= -> source-backed =SyntaxTree= index -> Element
projection. Upstream runtime no longer allocates a Rowan green/red tree or
copies individual token strings, but it still replays events to construct
navigation entries. Removing Rowan is not equivalent to removing this pass.
The old =rowan.build= diagnostic label remains historical plumbing, not
evidence that a Rowan dependency or a borrowed native view is executing.

The upstream direct FFI route is =gerbil-parser-native=: generate a language
pack, attach =NativeSession= to the existing owner-thread VM, create the

does not mean zero allocation. Syntax rejection remains distinct from
transport failure and must not become a fabricated accepted tree.

ownership and identity controls. No unsafe Send/Sync, leaked C result,
second VM, Rust grammar fallback or lowered concurrency is justified.
