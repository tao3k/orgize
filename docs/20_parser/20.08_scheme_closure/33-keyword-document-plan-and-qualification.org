#+title: Native keyword document plan and qualification

* Ownership and replacement

Program =01a9576b= extends the existing document semantic request (operation
17) with Scheme-owned keyword facts. The old private =org-headline-batch=
entry is replaced by =org-document-batch=, not retained as a compatibility
path. Keyword routing, words, tags, boolean options and last-option wins
remain the existing =org-keyword-facts= algorithm in Scheme.

Rust forwards source-backed raw keyword values with the existing TODO
configuration and headline inputs. It admits counted, ordered fact rows
against the current document's graph IDs, rejects malformed framing, and
owns the resulting values for that document's lifetime. The isolated
=org_aot_keyword_view.rs= owner performs transport admission, not grammar
recognition. Tests live in =tests/unit/org_aot_keyword_view.rs=.

The full semantic projection now reuses these facts instead of making a
second keyword request. Affiliation is a distinct lazy Scheme policy; the
focused reuse test admits that policy separately before measuring keyword
reuse. The cold whole-catalog and scale scenarios are not prewarmed.
Standalone keyword operations remain needed by existing standalone native
consumers; they are not a fallback parser.

* Resolved qualification failures

The first Scheme library run failed the new zero-request assertion because
it also counted the independent affiliation request. The repaired assertion
isolates keyword reuse and preserves metadata, Unicode tag deduplication,
ASCII case ownership and repeated-option semantics.

The first Rust ordinary catalog rejected an inline source test module under
=RUST-AGENT-PROJECT-003=. Its test body was moved to =tests/unit= and mounted
with =#[path]=. The gate is not suppressed. Both repaired catalogs pass.
Intermediate receipts retain their nonzero status; only the newly compiled
=*-admitted*= artifacts qualify this source.

the unchanged 25ms Contract gate. This keyword change is not tail closure:

The same 29 physical replies are observed in this Contract fixture; it does

the dominant wall-time component in these failed observations.

The minimal project Query index also does not run the full semantic keyword
projection. Its 1,016/10,160 replies are bounded parser packets plus one
document semantic plan per source, not repeated keyword projection calls.
Batching those document plans is a separate structural optimization; the
new keyword reuse assertion must not be promoted to that throughput claim.

Rust Query IR semantic construction and owned native view/result lease
handoff remain open. Whole-parser migration and stable 25ms admission are
not declared complete. No kernel patch, concurrency reduction, corpus
replacement, release-profile change or timeout relaxation is used.
