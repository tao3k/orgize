[[file:../20.08_scheme_closure_ledger.org][Native Scheme closure index]]

* Source owner and scope

The unpublished parser candidate is isolated in
=../gerbil-parser-native-migration=, based on published =49a527f2=.
The clean pinned parser and bridge checkouts are unchanged. Cargo and Gerbil
pins still select =49a527f2= / =1e4f1f65=; no local Cargo patch overrides are
used. The explicitly staged candidate SDK is not a published REV qualification.

Fold repeatedly converted an entire immutable line/helper window to UTF-8
inside byte predicates and offset scans. Dense-link paragraphs combine
many physical lines into one window, so repeating conversion per scanned
byte is quadratic. The parser-owned private cache now converts each window
once within a parse. Identity keys distinguish separate source objects;
nested parses restore the parent cache and subsequent parses start empty.
No cache is retained across calls, owner threads or mutable caller updates.

* Native migration still required

=Org::parse= still receives Scheme OEV1 events, decodes =TreeEvent= values,
and calls =parse_generated_events= to construct a flat source navigation
index before graph projection. Rowan is absent, but this materialization
has not been removed. The stage is accurately named =artifact.syntax_index=
through production observations, tests, benchmark admission and reports;
the dependency guard rejects the obsolete =rowan.build= metric.

Upstream GPA1 =NativeParsed= borrows an owner-thread session and language.
Those lifetimes cannot currently be returned to arbitrary Rust/Python caller
threads as an owned public syntax object. A complete cutover must introduce
an explicit owned result/runtime lease, prove payload release and shutdown
ordering, and adapt public navigation and graph consumers to that artifact.
An unsafe =Send/Sync= assertion, leaked session or parallel unused GPA1 facade
is not closure. Parsing/grammar policy stays in Scheme; host transport and
typed admission stay in Rust. No Gambit kernel changes are involved.

Publish the qualified parser owner change only with user authorization, then
align normal immutable revisions and requalify exact-head upstream CI.
