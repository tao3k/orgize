* Cohesive owner migration

Audit date: 2026-10-06. Public Org parsing remains the native Gerbil
AOT/FFI path. This owner moves BIBLIOGRAPHY, CITE_EXPORT,
PRINT_BIBLIOGRAPHY and nocite classification out of Rust.

=citation-export-value-funs.ss= is a pure native Scheme module. It owns
ASCII keyword classification, Unicode whitespace tokenization, double-quote
edge stripping, processor/style presence and plist option recognition.
The former whitespace-first behavior is preserved: quoted spaces are not
silently promoted to a new quoted-path grammar. Empty quote-only tokens
disappear; duplicate options, repeated leading colons, empty option keys,
optional values and order retain their previous semantics. Values stay inert.

Rust traverses the existing metadata/element/section/object graph in the same
order, preserving annotations, raw fields and occurrence multiplicity.
Keyword references are admitted in one native batch; citation styles in a
second batch only when citations exist. There is no per-keyword FFI crossing,
raw Rust token parser, new ABI opcode, evaluator or JSON semantic transport.
=citation_export_owner.rs= admits bounded indexes, nondecreasing row order,
closed tags, exact optional arities, option ownership and boolean values.
Derived graph-presence warnings and host effects remain Rust responsibilities.
