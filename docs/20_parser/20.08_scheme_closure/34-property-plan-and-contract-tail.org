includes public =Org::parse=, semantic projection, Contract source admission
and lint evaluation. The full catalog retains 457 cases and 12 callers.

An operation-profiled =01a9576b= diagnostic fails at 138.941792ms. Operation
23 accounts for 78.569544ms of synchronous transport wall time, operation

* Replacement and lifetime

Program =e3d634d0= introduces a closed =property-profile-plan= in the existing
Scheme value owner. One request returns descriptor keys, optional descriptor
names and cooked property tokens using the existing scalar algorithms.
Quoted/escaped tokens, mixed case, trailing plus and Unicode remain Scheme
semantics.

Rust collects exact key/value inputs, admits one ordered row per input and
holds those owned facts in a request-local =PropertyNativePlan=. Public
property-profile APIs keep their signatures and serialized model shape.
Property lint shares that same plan for profile construction, descriptor
classification and local/inherited allowed-value lookup. It does not create
a global cache, prewarm the Contract gate or interpret property syntax.
The replaced Rust scalar forwarding helpers and classification entry are
deleted rather than retained as a fallback.

The isolated assertions require exactly one native property-plan request
and no further request for inherited allowed-value lookup. The Scheme suite
compares every batch result against the existing scalar algorithms; private
Rust admission tests reject malformed shape/presence.
