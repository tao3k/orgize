#+title: Public engine source patterns and PR alignment

* Ownership

PR #13 commit =819eca38d3981d6079390dff7e5c66e4985cdad6= centralizes
=source-offset-after=, =source-pattern-end=, =source-pattern-at?= and
=source-ascii-ci-pattern-at?= in gerbil-parser. These named pure functions
project declaration-time literals into the existing event IR. They do not
introduce another user DSL, parser, callback ABI or mutable global cache.
Org retains grammar families, semantic policy and POO-native public models.
Thirteen grammar consumers import the public parser interface directly;
the old Org helper definitions and forwarding wrappers are removed.
Byte offsets use the engine's UTF-8 length primitive. ASCII-insensitive
matching rejects non-ASCII patterns rather than pretending to Unicode-fold.

Request-local execution now owns UTF-8 views, prepared byte membership and
private state slots. Helper frames are independent; join bindings are scoped.
Nested helpers and loops thread one reversed event chain and reverse it only
at publication. There is no kernel change or Rust-side grammar fallback.
