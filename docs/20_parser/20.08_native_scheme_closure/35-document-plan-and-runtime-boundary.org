* Architecture and ownership

AOT compiles the Scheme semantic owner; FFI admits counted native values.
Neither removes the need to queue a request, wake the single owner, retain
its root, copy a response and resume a caller. Both current runtime choices
still serialize execution within each linked Scheme domain. Tokio caller
concurrency is not a pool of independent Scheme VMs. A single actor that
blocks on native ingress is not evidence of green-thread work stealing.

The document projection previously called operation 10 once per block and
operation 16 once per implicit headline anchor. A document-level plan now
keeps the existing Scheme physical-line owner and batches block inputs.
Each response has an explicit counted header, including empty blocks.
The Rust adapter validates shape and UTF-8 ranges and constructs typed
annotations; it does not scan lines, normalize indentation or parse labels.

The block ingress batches at most 32 records and targets 256KiB of input
fields. A single larger block remains accepted under the existing native
line owner; this target is not a hard service-time or response-size bound.
Plans are requested only by full semantic projection, not by minimal parse
or filtered Query. No JSON interpreter or source-evaluation path is added.

Headline display-object projection precedes one Scheme document-anchor
operation. Scheme owns slug formation and traversal-order suffix allocation;
explicit CUSTOM_ID/ID values do not consume an implicit suffix, and empty
slugs remain absent. Rust applies admitted anchors before link resolution.
The old Rust scalar forwarding and suffix-counting algorithm are deleted.

The first Rust native-unit run exposed another crossing: =property()= called
=OrgDuration::parse= separately for every node property, even non-duration
values. Its new call-count assertion observed three replies instead of two
and failed; the =rust/library/library-test.log= receipt is retained. The
repair adds a bounded native =duration-plan= and typed record-ID admission.
The updated fixture contains valid, saturated and Unicode-invalid properties,
and expects exactly three replies for blocks, anchors and all four durations.
Standalone public duration parsing still uses its native scalar owner; full
document projection no longer does so per property.

Contract and property lint retain their native document plans. Syntax lint
uses lean source records rather than requesting unused Babel execution facts.
Rust Query/Contract IR validation and owned view/result leases remain open
semantic/lifecycle migration work, not disguised as completed FFI closure.

Property-plan input framing now deduplicates exact key/value pairs before
copying inherited values. Its deterministic byte order and native token owner
are unchanged; this avoids duplicate host allocations, not native semantics.
Feature-only =ast.block_document_plan=, =ast.anchor_document_plan= and
=ast.property_duration_plan= spans
separate these crossings from the shared operation-23 aggregate. Nested
observations overlap and must not be added as exclusive stage costs.
