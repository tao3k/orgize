* Ownership and replacement

The private Scheme =org-contract/document-plan.ss= owner accepts counted
parser-owned section properties and ordered source blocks in one request.
Scheme owns property selection/last-wins normalization, aliases, kind/scope/
severity policy, block roles and native cooked expression/expectation/Contract
composition streams. Malformed streams remain explicit per-block outcomes:
they neither poison other blocks nor become default successful assertions.
Framing is fully decoded before grammar work begins, with bounded count
validation and no repeated remaining-list length scan.

Rust =org_contract/source_plan.rs= admits row counts, closed tags, presence
flags, balanced cooked-value nesting and source-local indices. Its borrowed
document anchors the call-local section mapping; Rust addresses never cross
FFI and are never dereferenced from wire data. Source identity and range come
from the existing lean parser-owned projection, not another Org parse/tree.
Registry extraction and diagnostics consume the same admitted plan.

Removed paths include the Rust metadata-only batch requester, per-property
normalization/classification calls, Contract/Expectation raw-source forwarding
wrappers and the four unused string-based Query/Contract admission/compiler
entrypoints. Their tests now exercise the public document-level path instead
of resurrecting a test-only legacy parser. Syntax lint shares the same native
admission; an empty source-block catalog does no work.

The existing operation-23 ONR1/OXV1 identity-bound ABI carries the new private
mode. There is no JSON transport, new parser, compatibility fallback, public
authoring DSL or host evaluator callback. Pure native grammar functions
produce cooked values. Host filesystem/path aliases and typed Query IR
projection remain Rust responsibilities in this candidate.

admitted cooked values; this candidate does not certify a fully Scheme-owned
Query IR compiler or whole-parser semantic closure.
