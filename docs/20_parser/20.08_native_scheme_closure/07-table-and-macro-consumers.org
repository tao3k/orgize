** Native ownership and thin Rust admission

=event-source-content.ss= supplies pure bounded source-content declarations
shared by table cells, formula components and MACRO helpers. ASCII whitespace
and Unicode White_Space are recognized over complete UTF-8 sequences without
probing outside the admitted slice. Lossless leading/trailing trivia remains
in the event tape; semantic content and its range are declared by Scheme.
Left-trim-only MACRO templates retain their trailing source bytes.

Tables now declare =TableCellContent= and formula value, assignment, LHS and
RHS =FormulaContent= nodes. Flag content has its own =FormulaFlagContent=
role, avoiding accidental projection of a nested flag into assignment text.
Rust =aot_table_projection.rs= reads native content fields and cell field
ranges; cell trim/offset reconstruction and formula/flag trimming are removed.
These transparent table wrappers do not change public table record IDs,
ancestry or raw ranges. The exact representative snapshot refresh adds only
the four expected cell content fields/ranges; no blanket refresh is used.

=event-macro.ss= owns definition-name admission, definition/template bounds,
comma segmentation, escape parity, empty argument omission and cooked
argument chunks. Escaped commas and backslashes discard only the native
escape trivia; unknown escapes and terminal backslashes remain literal.
The native graph exposes definition name/template and source-ordered
=macro-argument= records. Rust =preprocessing.rs= is a field admission decoder;
the old name validation, trim, whitespace search and argument scanner are
removed. Invocation consumers decode the declared argument records directly.
New public argument records can change source-ordered IDs in macro-bearing
documents; do not generalize the table ID-preservation claim to them.

The native regression family lives in
=tests/unit/aot_projection/native_content.rs= (215 lines), with the main
startup catalog owner at 875 lines. Every catalog entry remains enabled.
The tests cover 12 whitespace fixtures for table source extents, CRLF, empty
cells, formula flags/references; seven invocation argument fixtures including
Unicode, escaped comma/backslash and malformed tails; and four invalid
definition names. Existing header consumer regressions are retained in the
same content test module.

** Remaining global migration boundary

Table content and MACRO definition/argument syntax are admitted, but full
Scheme semantic ownership is not yet closed. The next cohesive migration
must remove both copies of Rust template scanning in =macro_expansion.rs=
and =org_contract_evaluation.rs= together and qualify expansion consumers.
Rust template execution is not proven native by the syntax tests above.

Literal block metadata still owns line splitting, indentation, code
references and numbering in =block_metadata.rs=. Keyword settings still
require a native-runtime boundary audit: generated Rust
=org_aot::keyword_*= helpers and prescan trims do not establish Scheme runtime
ownership. Runtime path/link resolution and radio matching must be
classified separately from parser syntax instead of indiscriminately
deleting string operations. Public Org::parse has no legacy Rust parser
fallback; that entrypoint fact must not hide these remaining semantic owners.

** One Scheme semantic owner and existing FFI handoff

=modules/org-parser/macro-funs.ss= owns pure template expansion. Literal
Unicode, =$$=, =$0=, single-digit numbered placeholders, missing arguments,
unknown placeholders and terminal dollar signs retain their admitted behavior.
Argument indexing is constructed once as a vector; repeated placeholders no
longer traverse the entire argument list. Joined =$0= text is computed lazily
once per expansion. Native tests exercise 1,000 and 10,000 arguments and
repeated placeholders. These are functional/scaling fixtures, not document
throughput measurements or proof of an end-to-end optimization gain.

The same module expands Contract property macros from native inline events.
=parse-org-inline-events= is a POO strategy using the existing inline helpers,
not a second file parser or a hand-written comma/escape scanner. It preserves
source byte extents, literal malformed/unknown calls, valid code/verbatim
regions, Unicode, CRLF and native cooked argument chunks. Source-ordered
definitions retain last-definition priority. Templates are not recursively
evaluated, and this pure owner does not execute host commands.

Rust =macro_expansion.rs= keeps the public side table and typed definition
index, but its template operation is now a thin native handoff.
=org_contract_evaluation.rs= encodes admitted definition fields and receives
the native secondary-value expansion. Its duplicate template scanner,
=org_macro_token= and =parse_macro_body= are deleted. The existing public
side-table shape, missing-definition status and lossless document behavior
remain; expansion now uses the explicitly initialized native runtime, also
for manually constructed typed Documents.

Private ONR1 operations 8/9 use counted UTF-8 fields and return one
grammar-identity-bound OXV1 string value. Scheme validates complete lengths,
field counts, pairing and trailing bytes before semantic execution. Rust
only encodes fields and decodes the result, through the existing =org_aot=
facade and native owner. NUL-containing strings and rejection followed by
owner recovery are exercised on both lifecycle lanes. The existing C export,
root lifetime and bounded queue/actor handoff remain; no new public C ABI,
JSON semantic transport, Python framework, kernel patch or concurrency
reduction is introduced. Python installed-package qualification is not claimed
by these Rust/native receipts.

** Still-open whole-parser migration

The macro definition/argument/template/secondary-value consumer family is
now admitted natively. This does not close literal block line metadata
(splitting, indentation, code references, numbering) or keyword settings and
prescan/generated Rust helpers. Contract DIR environment/command token
recognition also remains Rust syntax and needs its own native plan admission;
environment lookup, process execution and filesystem/path operations must
remain explicit host handoffs. Neither category is silently called native by
the macro tests above. Runtime linking/radio matching must be audited by role.
Global Scheme semantic ownership and stable performance closure remain open.
