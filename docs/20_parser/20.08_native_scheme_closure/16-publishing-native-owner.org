* Ownership and executable boundary

2026-10-06: Publishing source policy moves from Rust to the pure
=org-parser/publishing-value-funs.ss= owner. Scheme classifies export/setup,
backend and attribute keywords; trims Unicode whitespace; splits inert BIND
values and OPTIONS at the first colon; admits every closed option kind.
Empty fields, duplicate order, ASCII case rules and repeated ATTR_ prefix
behavior are preserved. No BIND value is evaluated.

Rust collects graph-local keyword references, makes one native batch crossing
per nonempty document, admits ordered/bounded keyword indexes and closed row
shapes, and attaches annotations. Includes remain the existing projection.
It contains no Publishing split/trim/case/prefix source interpreter.
The adapter fingerprint now includes this owner. This removes per-keyword
crossings by construction, but is not a measured end-to-end speedup.

The existing public Publishing consumer retains its snapshot and additionally
checks Unicode whitespace, duplicate export replacement, optional BIND values,
inert Scheme text and malformed/duplicate/colon-bearing OPTIONS. Its catalog
registration remains unchanged: 457 consumers, not an invented extra count.
