* Owner audit

Audit date: 2026-10-06. This owner closes all 30 production library warnings
identified by record 20, not just a selected subset. Each was an unused
function in =org_native_semantic_functions.rs=; none was a native grammar,
runtime lifecycle or ABI implementation failure.

keyword-match helpers (four), headline priority cookie (one), attachment

affiliated-keyword predicate (one). Their unused imports did not count as
test coverage. Scheme implementations and the native ABI are not deleted.

=tests/integration/support/native_semantic_values.rs=. The test adapter
contains only its 20 actually used probes; it does not include all of the
production module a second time. All 12 existing consumer cases remain
registered, with their assertions unchanged.

The production module shrinks to 89 lines and contains eight
actually used interfaces plus typed scalar/closed-category admission.
Borrowed field references replace allocate/push boilerplate where an
owned field vector is unnecessary. Scheme still drives the semantics.
There is no warning suppression, feature disabling, test deletion,
new parser, kernel patch or optimization-profile reduction.
