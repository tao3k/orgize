* Native state operation

State lookup, typed lookup and update move from the large Fold runtime into
a private pure module. Runtime reexports preserve existing consumers.
The update traverses immutable state without mutating entries or tails:

- If every matched value is identical, return the original state spine.
- Otherwise copy the prefix through the last changed entry and share the
  unchanged suffix and entries.
- Update every matching name, including repeated names; retain missing-name
  update behavior and typed lookup errors.

Traversal and lookup remain O(S). This is not an indexed-state implementation,
and sharing state nodes is not a measurement of total process allocation,
peak heap or transient call-frame allocation.

Generic conformance tests belong to the parser's
=t/event-fold-state-test.ss=. Orgize's =t/native-fold-state.ss= only supplies
the native standard harness, the existing diagnostic clock and a test-only
reference implementation import. No production fallback or new test runner
is introduced.

The final native control passes five generic cases plus one measurement
case, with 20 fixed reference/candidate samples: 64 states and 10,000
updates, no-change/front/middle/tail cases, five repetitions each.
State parity and original-state immutability are asserted. Deterministic
identity checks prove whole-spine reuse and shared suffixes. Wall time and
thread CPU are reported separately, with no timing-based oracle.
The intentional failed assertion returns final FAILED and exit 42.
The original unified control and its negative timing samples are retained
as =control= and frozen =fold-state-control-v1=; final split-owner evidence
is =control-split=.

Features were run sequentially, not as repeated alternating performance

* Remaining architectural and publication gates

The candidate does not remove linear named-state/helper lookup or
runtime dispatch over statement/predicate IR. Production host workers
still share one native owner per process. Native state layout / compiled
Fold accessors and plan specialization require separate exact semantic
and controlled performance evidence; no new mutable public DSL,
stale global cache, compatibility parser or runtime-kernel patch is justified.

Clean parser and bridge publication, platform CI, standalone C/wheel
distribution, historical latency tails and whole-parser grammar closure
remain independent. Source sharing is not a reason to declare them closed
or switch the default native program.
