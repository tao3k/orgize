#+title: 20.07 Complete Org Parser Cutover Audit
#+startup: overview

* Verdict

The public =Org::parse= and =ParseConfig::parse= paths use the Org-owned Scheme
event algorithm AOT-compiled to Rust/Rowan. The handwritten =src/syntax= parser
and its typed-syntax export API have been removed. Ordinary Cargo consumers do
not run Gerbil or consume Python parser artifacts.

The replacement is *not yet semantically complete*. The Scheme source, AOT
event IR, Rowan tree, and Element graph are the parsing authority. The owned
=Org::document()= adapter and several downstream feature consumers still lack
fields or behavior once supplied by the removed implementation. Reintroducing
a Rust Org recognizer is not a valid way to close those gaps.

* Current gates

At the current PR working tree on 2026-09-28, the Scheme suite reports
=HARNESS-OK= and =OK=, =cargo fmt --all -- --check= passes, and strict Clippy
passes for the workspace with all targets and features. The full Rust
integration target reports *375 passed, 64 failed, 2 ignored*. These focused
receipts do not constitute parser or release closure; check the exact pushed
head and platform CI again after every change.

* Remaining ownership work

| Boundary | Required closure |
|----------+------------------|
| Org Scheme grammar and event algorithm | Finish contextual recovery and complete Elements/Objects, including source-backed title/object ranges and fixture ancestry. Colon-qualified property keys are now covered in Scheme and Rust graph tests. |
| AOT/Rowan graph | Project every source-backed semantic field used by the public parser, including affiliated keywords, tables, links, and user-configured headline state. Planning, clock, and inline timestamps now share Scheme-classified child Objects; the generic graph supports repeated node-text fields. Generic IR mechanics belong in gerbil-parser/gerbil-scheme-rust; Org syntax stays in orgize. |
| Owned semantic projection | Derive generated headline anchors, remaining link metadata, diagnostics, and lifecycle facts from graph fields without reparsing Org text in Rust. Title objects, filetags/inherited tags, effective properties, explicit ID anchors, timestamp metadata, clock duration, graph-backed target definitions, source/example block switches and body lines, and Scheme-AOT link classification plus document-local resolution now project from the AOT graph. |
| Consumers | Migrate contract, Elements query, lint, exporters, agenda, clock, and Python/wasm surfaces to the same graph and verify their behavior against Git-tracked fixtures. |
| Performance and release | Benchmark parse and projection hot paths on current AOT code, resolve strict policy warnings, and require clean exact-head cross-platform CI. Old parser-v2 benchmark numbers are not valid AOT baselines. |

* Acceptance

The cutover is complete only when the Scheme suite, full Rust workspace test
matrix, strict policy, source-roundtrip/graph checks, consumer fixtures, and
current AOT performance gates pass at the exact PR head on required platforms.
An individual green fixture or a decreasing failure count is progress, not
completion.
