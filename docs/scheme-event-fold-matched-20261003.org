* Method
The Justfile entry scheme-event-benchmark calls the existing ASP
benchmark-elapsed-us and benchmark-memory-usage helpers on committed Criterion
input files. Imports, input I/O, semantic admission and two warmups are untimed.
Every sample's complete event list must equal its untimed expected value.
Input and full event SHA256 digests match between baseline and candidate.

Each cell below has 20 independent samples. Separate processes run sequentially;
second-round baseline/candidate order is reversed for each fixture. No competing
test/build was intentionally launched during the retained measurement batches.
Both processes have a 1G heap cap and a 30-second external timeout.

Gambit's allocation counter is published at GC: collect before the allocation
snapshot and after the timed parse, outside timing. Early probes lacking the
post-parse collection reported misleading constant deltas and are excluded.
The first overlapping process probes are also excluded.

* Discarded design and gates
The earlier per-recursion parameterize cache allocated 19,007,568 bytes on
doc.org versus baseline 14,767,872, without stable time improvement. It is
replaced by one parse-local bounded cache entry; changing helper slices replaces
that entry and caller identity is checked on reuse.
