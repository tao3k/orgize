#+TITLE: Native Query/Contract syntax admission and Rust lint ownership

* Ownership

The Rust lint implementation now lives entirely under =src/lint/=:

- =mod.rs=: declarations and unchanged public reexports only.
- =pipeline.rs=: ordered entrypoints, execution policy and finding collection.
- =model.rs= and =render.rs=: result model, location projection and presentation.
- =rules/=: document metadata, Query/Contract syntax and the existing domain rules.
- =runtime_validation.rs=: bounded host execution and evidence, separate from syntax.

There is no root-level =lint*.rs= implementation or compatibility forwarding module.
CLI imports, the ASP file-link verification hint and Justfile formatting ownership
follow the new paths. Existing public =orgize::lint= entrypoints remain unchanged.

* Native syntax authority

Query, Contract and selector expressions now use the canonical Scheme
=parse-org-contract-expression= through the existing native parse transport.
The generated Rust LanguageSpec remains a Rowan kind/catalog projection, not
an executing lexer/LR parser. The independent Rust selector tokenizer was removed.

Both runtime features use the same private =ONR1= request and =OEV1= event tape.
Operation and grammar identity are checked; old nine-byte requests are rejected.
No process parser, extra runtime owner, Gambit patch or startup fallback was added.

The syntax stage reads parser-owned raw SourceBlockRecord values before registry
evaluation. =ORG046= is an Error for invalid or unsupported Query, selector,
expectation or Contract block syntax, including unregistered blocks.
It reuses existing semantic lowering owners rather than declaring another grammar.
Diagnostics currently point to the source block, not an exact expression token.

Fixed-arity forms reject ignored extra arguments. Unknown category no longer
silently becomes an unrestricted query. Contract compilation rejects unconsumed
forms and duplicate binding declarations. An explicitly invalid expectation
cannot fall back to =exists=.

features. The new native closure requires fresh 1,000/10,000-document, 1/8-caller
