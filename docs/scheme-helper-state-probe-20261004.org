is native linking and ordinary consumer validation of this separate manifest
under both =runtime-rust= and =runtime-scheme=, followed by the maintained Tokio
1000/10000-document admission and semantic checks. Native scale lanes must

module cache proves neither. Strict Query and Python qualification remain open
for this candidate.
