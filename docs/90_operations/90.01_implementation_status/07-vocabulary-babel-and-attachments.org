*** M29.1 Literate Source Reference Projection

- [X] Add =SourceBlockReference= and =SourceBlockReferenceKind= to the semantic
      AST API so host tools can consume non-executing Babel edges separately
      from source-block definitions.
- [X] Resolve =#+CALL: name(...)= targets after trimming Org's ordinary keyword
      spacing, covering a long-standing lint blind spot where =#+CALL: foo()=
      did not produce a missing-target warning.
- [X] Treat native Babel keyword entry points case-insensitively so lowercase
      =#+name=, =#+call=, and =#+results[...]= feed the same semantic source
      block name, call-reference, and result-evidence projections.
- [X] Expose source-block references through wasm =sourceBlocksJson= with
      =kind=, =target=, =resolved=, and source range fields.
- [X] Split wasm source-block DTO tests into a dedicated owner so the harness
      large-test-leaf policy stays enabled.

*** M29.2 Babel Header Variable Dependency Projection

- [X] Extend =SourceBlockReferenceKind= with =HeaderVar= so
      =:var data=name= and =:var data=name(args)= source-block dependencies

- [X] Keep =:var= literal assignments such as numbers, quoted strings, lists,
      and ambiguous bare non-source names out of missing-source diagnostics, so
      named tables and ordinary literal values are not misreported as broken
      source blocks.
- [X] Resolve Babel calls and header variables only against local =#+NAME=
      source blocks, while noweb references continue to accept both =#+NAME=
      source blocks and explicit =:noweb-ref= declarations.
- [X] Expose header-variable reference edges through wasm =sourceBlocksJson=
      with optional =variable= metadata.
